# USB Print

A small Android app for direct USB/OTG printing, with no ads and no premium print wall.

## Current milestone

**Phase 1: USB device detection**

The app can:
- Detect USB devices connected through OTG
- Identify printer-class USB devices
- Display USB vendor/product IDs
- Request Android USB permission
- Show the connection state

## Target printer

Initial testing target: Canon USB-only printer from the imageCLASS LBP6030 family.

## Next milestone

Open a USB connection to the Canon printer and perform a controlled test print before implementing PDF/document printing.
